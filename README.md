### 🚀 Como Usar

#### Visualizar Localmente
```bash
# Opção 1: Abrir diretamente
# Clique duas vezes em index.html

# Opção 2: Servidor local com Python
python -m http.server 8000

# Opção 3: Servidor local com Node.js
npx serve

# Opção 4: VS Code Live Server
# Instale a extensão "Live Server" e clique com botão direito > "Open with Live Server"
```

#### Personalizar
1. **Cores** - Edite as variáveis CSS em `style.css` (linhas 9-20)
2. **Conteúdo** - Edite o texto em `index.html`
3. **Imagens** - Substitua as imagens por fotos reais
4. **Projetos** - Edite as páginas `projeto-X.html`
